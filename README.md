# Airbnb-Booking-online
# Airbnb Landing Page Clone

A **responsive** and visually appealing landing page inspired by Airbnb's website, built with **HTML5**, **CSS3**, and vanilla **JavaScript**.  
This project features a clean layout including a search hero section, image slider, multiple property listings, and a detailed footer, mimicking key UI elements of Airbnb.

## Features

- Responsive header with navigation and logo  
- Hero search section with inputs for location and check-in/check-out dates  
- Image slider/carousel with Prev/Next buttons for browsing featured images  
- Property listings displaying images, descriptions, and booking buttons  
- Comprehensive footer with contact info, social media links, opening hours, and informational sections  
- Modular CSS files for styles, slider, and footer for clean separation of concerns  
- JavaScript-powered slider for smooth image transitions  
- Normalize.css for consistent cross-browser styling  

---

## Technologies Used

- **HTML5** for semantic structure  
- **CSS3** with modular stylesheets and responsive design  
- **JavaScript** (vanilla) for interactive slider functionality  
- **Normalize.css** to reset and standardize default browser styles

## Project Overview

This project is a **web application inspired by Airbnb**, designed to showcase unique accommodations and experiences worldwide.  
Users can browse a diverse selection of listings — from cozy apartments to modern lofts — complete with detailed descriptions, images, and booking options.  
The platform aims to provide an engaging and intuitive way for travelers to discover and book memorable stays.

For more about Airbnb, visit [airbnb.com](https://www.airbnb.com/).
